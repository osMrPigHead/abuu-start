# 航启主页 / BUAA-Start 二阶段 PRD

## 1. 二阶段目标

- 在单用户桌面主页上，补齐 **SPOC、博雅课程、阳光打卡** 三类教务信息的只读聚合。
- 增强番茄钟：阶段结束**自动开始下一阶段**，并增加桌面通知。
- 延续一阶段边界：本地只读中继、手动凭据、缓存优先、按数据源隔离错误、不做任何写操作。

二阶段完成标准：五类教务数据（课表、考试、SPOC、博雅、阳光）可在主页与对应页面稳定展示；番茄钟可自动流转并按设置发送通知；断网、无凭据、凭据失效均有明确状态。

## 2. 与一阶段的关系

- 一阶段已交付：主页基础、快捷入口、本地待办、番茄钟、课表、考试、设置、本地中继。
- 二阶段新增：SPOC 真实接入（一阶段为占位/待接入）、博雅课程、阳光打卡。
- 二阶段变更：番茄钟阶段结束后自动开始下一阶段，替代一阶段 3.4 的“停在下一阶段、由用户手动开始”；一阶段该条验收在二阶段不再适用。
- 一阶段 2.3 的非目标在二阶段继续有效：多用户/权限、移动端、SSR/Pinia/React、任何写入、研究生 GSMIS、管理后台/成绩管理/教室预约。
- 一阶段 2.2 中未进入二阶段的项：快捷入口自定义图标/分组、应用内统一登录、中继加密存储凭据；二阶段继续不做。

## 3. 本期必须

- SPOC：启用凭据区，接入作业列表与只读详情，主页待办聚合 SPOC 段。
- 博雅：已选课程进入主页日程卡片与 `/schedule` 周视图；新增 `/bykc` 课程广场（分页列表 + 详情 modal）；主页新增随机推荐卡片。
- 阳光：主页卡片展示学期次数/目标/进度、当周次数/周限制；不设详情页。
- 番茄钟：阶段结束自动进入下一阶段；桌面通知（结束前 1 分钟 + 结束时）；设置页开关。
- 认证、缓存、刷新与错误：新增博雅/阳光凭据；四类数据源独立状态；沿用缓存优先与手动刷新。

### 3.2 本期不做

- 快捷入口自定义图标/分组、应用内统一登录、中继加密存储凭据。
- 博雅选课/退课/签到、广场筛选与搜索、已选课程独立页面。
- 阳光详情页、打卡/补卡/上传。
- SPOC 提交/附件下载、已提交/已截止作业视图。
- 番茄钟专注统计、待办关联、自定义通知文案。
- 一阶段 2.3 的全部非目标，以及研究生 GSMIS、管理后台、成绩管理、教室预约。

### 4.4 番茄钟通知与自动流转

| 需求 | 验收 |
| --- | --- |
| 阶段结束后播放提示音，并**自动开始下一阶段** | 专注结束自动进入短休/长休；休息结束自动进入专注 |
| 专注轮次达到配置值后自动进入长休 | 轮次与长休切换正确 |
| 首次开始仍由用户点击；暂停、继续、重置保留 | 重置后停止并回到当前阶段起点 |
| 专注卡片在剩余时间上方显示当前阶段（专注/短休/长休） | 自动流转后阶段文案同步更新 |
| 预计完成时间仅在运行中且未暂停时显示 | 暂停或未开始时该行隐藏 |
| 设置页提供“番茄钟桌面通知”开关；未明确关闭时默认开启 | 开关状态持久化；用户主动关闭后刷新仍关闭 |
| 首次开启或首次开始专注时请求系统通知权限；被拒绝时开关回到关闭并提示 | 拒绝后不反复弹权限请求 |
| 设置页显示通知权限状态，并提供“测试通知” | 可确认浏览器与系统是否放行桌面通知 |
| 阶段结束前 1 分钟发送一次通知（即自动流转下下一阶段开始前 1 分钟；仅阶段时长大于 1 分钟时） | 剩余 60 秒时触发一次，文案如“专注还剩 1 分钟”；暂停期间不计时，恢复后仅在首次跨过 60 秒边界时触发，不补发暂停期间通知 |
| 阶段结束时发送通知，内容含刚结束阶段与下一阶段 | 文案如“专注结束，已开始 5 分钟短休” |
| 点击通知聚焦航启页面 | 浏览器窗口获得焦点 |
| 通知不可用或权限被拒绝时，提示音与自动流转仍正常 | 不阻塞计时 |
| 页面在后台时仍按结束时间校正；跨过多个阶段时直接进入当前阶段，不补发历史通知 | 回到页面后阶段与剩余时间正确 |

### 4.5 认证、缓存与错误

| 需求 | 验收 |
| --- | --- |
| 四类数据源独立凭据：byxt Cookie、SPOC Token+RoleCode、博雅 auth_token、阳光 UID+token；凭据不写入缓存 | 各自保存、校验、清除互不影响 |
| 每类数据源独立显示“未配置/已配置/已失效” | 单源失效不改变其他源状态 |
| 缓存优先：先展示上次缓存，再后台请求；成功后更新时间 | 有缓存时首屏有内容 |
| 请求失败保留缓存并标注缓存时间；认证失效时标题标签显示“已失效/未登录” | 断网仍可读 |
| 无缓存且失败显示错误与重试，不显示成空数据 | “取不到”与“没有”文案不同 |
| 提供手动刷新；不做定时轮询 | 无自动轮询 |
| 清除缓存与清除凭据分开 | 清除凭据不清缓存，反之亦然 |

## 6. 通用规则

- 单用户；数据只存本机，不做云端同步。
- 桌面优先，最小支持宽度约 1024px；不做移动端布局。
- 只读：不提供 SPOC 提交、博雅选退课/签到、阳光打卡、教务管理入口。
- 时间按浏览器本地时区显示；教务时间按学校原始时间解释。
- 技术约束不变：Vue 3 Composition API + `<script setup lang="ts">`、TypeScript strict、Vite、Tailwind CSS、Vue Router 4；不引入 Pinia；HTTP 统一封装在 `src/api/client.ts`。
- 本地只读中继仍是唯一后端；除它之外不引入其他后端，不引入 SSR。
- 博雅 auth_token 与阳光 UID/token 均为手动凭据；过期后显示“已失效”，不自动续期、不保存账号密码。

## 7. 边界与失败情况

- 首次使用：四类凭据均未配置，各模块显示引导与空状态，不显示成“无数据”。
- 博雅/阳光凭据过期：对应数据源显示“已失效，需重新认证”，保留缓存并标注时间。
- 无博雅凭据：无缓存时主页与周视图不显示博雅课程，有缓存时显示缓存并标注时间；byxt 课程正常；博雅广场卡片无缓存时显示引导。
- 博雅课程与 byxt 课程时间冲突：两者都显示，博雅带来源标记。
- 博雅广场第一页不足 3 门：随机卡片显示实际数量；“换一批”在不足 3 门时仍可用。
- 广场末页：下一页禁用；上一页在首页禁用。
- 阳光系统目标缺失或为 0：使用用户设置值（默认 20）；用户值也非法时回退 20。
- 阳光当周次数超过周限制：进度条封顶 100%，文字显示实际次数。
- 通知权限被拒绝或浏览器不支持：开关不可用或回到关闭，提示音与自动流转不受影响。
- 阶段时长不超过 1 分钟：不发送“结束前 1 分钟”通知，只在结束时通知。
- 页面后台导致计时延迟：按结束时间校正，跨过多个阶段时直接进入当前阶段，不补发历史通知。
- 中继未启动：各教务模块显示连接错误与启动提示，不白屏；本地待办、番茄钟、快捷入口仍可用。
- localStorage 不可用或损坏：提示并降级为内存状态，不阻塞页面。

## 8. 假设与依赖

- 博雅接口依据参考 B：`auth_token` 请求头、`queryChosenCourse`、`queryStudentSemesterCourseByPage`、`queryCourseById`；广场分页与详情字段以参考 B 的 DTO 为准。
