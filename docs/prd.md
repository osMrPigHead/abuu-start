# 航启主页 / BUAA-Start PRD

## 1. 目标与用户

- 面向**单用户**的桌面浏览器主页。
- 提供快捷入口、待办、番茄钟，以及北航教务信息的**只读**聚合。
- 前端为 Vue 3 SPA，无 SSR；通过**本地中继**访问教务系统。
- 不面向多用户，不做移动端适配。

### 术语

| 术语 | 含义 |
| --- | --- |
| 完全功能模式 | 主页默认形态：显示时钟、搜索框、时钟行按钮与功能区。 |
| 仅时钟与背景模式 | 主页只显示时钟与背景的形态：隐藏搜索框、时钟行按钮与整个功能区；不显示切换按钮，点击视口任意位置退出。 |

## 2. 范围

### 2.1 本期必须

- 主页基础：时钟与日期、Bing 搜索、随机背景、快捷入口。
- 本地待办与 SPOC 待办聚合。
- 番茄钟。
- 教务聚合：日程（byxt 课表 + 博雅已选课程 + 考试）、考试详情、SPOC、博雅课程广场、阳光打卡。
- 统一登录、中继加密凭据、认证状态与缓存。
- 主页卡片开关、仅时钟与背景模式、本机目录背景。

### 2.2 本期不做

- 多用户、账号体系、权限管理、账号切换、云端同步。
- 移动端适配；仅保证桌面端。
- SSR、Pinia、React。
- 任何教务业务写操作：作业提交、阳光打卡、博雅选退课/签到、教务管理操作、附件下载。
- 研究生 GSMIS 课表；仅支持本科 byxt。
- 注册、找回密码、修改密码；验证码识别、自动填写或第三方打码。
- WebVPN、校外加密接入、连接模式选择。
- 快捷入口自定义图标/分组、卡片顺序拖拽。
- 博雅广场筛选与搜索、已选课程独立页面；阳光详情页；番茄钟专注统计、待办关联、自定义通知文案。
- 背景轮播、定时切换、模糊度等外观自定义；用户目录图片复制进仓库。

## 3. 功能与验收

### 3.1 时钟、日期、搜索

| 需求 | 验收 |
| --- | --- |
| 时钟显示本地时间 `HH:mm:ss`，每秒更新；日期显示年月日与星期 | 时钟持续走时；跨分钟/小时更新正确 |
| 搜索框固定使用 Bing；回车在当前标签页跳转；空输入不跳转 | 输入关键词后能正确编码并打开 Bing 结果页；空输入无动作 |
| 本期不做搜索引擎切换 | 页面无对应入口 |

### 3.2 背景

| 需求 | 验收 |
| --- | --- |
| 未配置自定义目录时，从仓库内置图片中随机展示；加载失败回退深色底或渐变 | 每次打开随机一张；失败不出现破图 |
| 设置页可配置本机绝对路径目录，保存、清除、重新扫描 | 保存后立即改用该目录；清除后回到内置背景 |
| 只扫描目录第一层，支持 jpg、jpeg、png、webp、gif、bmp、avif；子目录与其他文件忽略 | 子目录图片与非图片文件不出现 |
| 每次打开或刷新随机选一张；同一会话内所有页面共用同一张 | 连续刷新出现不同图片；子页面与主页一致 |
| 加载自定义背景期间不显示内置背景，加载完成后渐入；失败回退内置背景 | 加载期间不出现内置图切换；成功后渐入 |
| 目录不存在、无图片、无权限或读取失败时回退内置背景并提示，保留已保存路径 | 不出现破图；目录恢复后可重新扫描 |
| 损坏或超过 20 MB 的图片跳过；单张读取失败换下一张，连续失败才回退内置背景 | 不阻塞其他图片；单张失败不直接变成内置背景 |
| 背景层固定铺满视口，不随页面滚动或触摸板滑动产生位移；沿用暗角遮罩 | 滚动时背景不移位；文字可读性不下降 |
| 用户目录图片不复制进仓库、不写入缓存 | 仓库无新增图片；缓存中无图片数据 |

### 3.3 快捷入口

| 需求 | 验收 |
| --- | --- |
| 支持新增、编辑、删除；字段为标题 + URL；用户可添加任意 http(s) 链接 | 增删改后刷新仍保留 |
| 非法 URL（非 http/https，如 `javascript:`）被拒绝 | 保存时提示并阻止写入 |
| 支持行内和跨行拖拽排序；快捷方式可放在 11 行中的任意一行，每行数量不限，超出视口后横向滚动 | 拖拽位置刷新后仍保留；不自动换行 |
| 点击在当前标签页打开 | 不发生新标签页跳转 |
| 自动读取站点 favicon；失败时显示首字母占位 | favicon 失败不出现破图 |
| 本期不做自定义图标、分组、卡片顺序调整 | 页面无对应入口 |
| 快捷入口数据保存在本机 | 刷新浏览器后保留 |

| 登录成功后显示姓名、学号与登录时间，并提供退出登录 | 信息与上游返回一致；退出后回到未登录 |
| 登录中禁用重复提交；登录成功后四类数据源自动刷新一次 | 重复点击不产生并发登录；无需手动刷新即可看到数据 |
| 上游要求验证码时展示图片与输入框，并提供刷新验证码 | 出现验证码时可输入完成登录；刷新后图片变化 |
| 登录失败分类提示：账号或密码错误、验证码错误或过期、密码过期或账号存在安全风险、网络或上游失败、需要重新登录 | 文案可区分，不统一显示“登录失败” |
| 登录成功即整体成功；各数据源独立显示“已派生/派生中/派生失败/已失效/未派生”，失败项可单独重试 | 博雅派生失败不影响 byxt、SPOC、阳光 |
| 凭据由中继保存并注入请求；前端不保存、不发送凭据 | localStorage 与本机请求头中无 Cookie、Token、RoleCode、UID、密码 |
| 凭据与派生会话由中继加密保存在本机用户数据目录；密钥独立存放 | 本机存在凭据文件；文件中无明文；其他用户不可读 |
| 前端 localStorage 不再保存任何凭据；升级后清除旧凭据键 | 升级后需重新登录一次；localStorage 中无凭据字段 |
| 中继日志与错误响应不含凭据、密码或 token | 日志仅含方法、路径、状态、耗时 |
| 退出登录清除中继会话、保存的凭据与业务缓存；保留待办、快捷入口、番茄钟设置、背景目录、卡片开关与显示状态 | 退出后无残留登录态；本地偏好不丢失 |
| 会话过期时中继用已保存凭据自动重新登录一次；仍失败则显示“已失效”并保留缓存 | 过期后可自动恢复；失败不显示成“无数据” |
| 主页启动不等待登录校验：认证校验异步进行，缓存优先取数与校验并行 | 慢网或中继不可达时首屏不被校验阻塞；校验期间不误显示“未登录” |
| 未登录时主页不新增横幅；各卡片沿用标题状态标签引导到 `/settings` | 主页无新增常驻提示 |
| 仅支持直连；不提供 WebVPN 或连接模式选择；不提供注册、找回密码、修改密码 | 页面无对应入口 |

### 3.12 主页卡片与仅时钟模式

| 需求 | 验收 |
| --- | --- |
| 设置页提供五个独立开关：日程、博雅课程广场、待办、专注、阳光打卡；默认全部开启 | 五个开关可分别切换并立即生效 |
| 关闭后该卡片不显示，且不再发起该数据源请求；重新开启时按缓存优先刷新 | 关闭期间无该源请求；开启后先显示缓存 |
| 卡片顺序固定为日程、博雅课程广场、待办、专注、阳光打卡；左列日程、待办，右列博雅、专注、阳光 | 隐藏后同列后续卡片按原相对顺序上移，不留空行 |
| 功能区始终为 11 行；快捷方式仍可放在 11 行中的任意一行，行数与行号不随卡片开关变化 | 编辑态放置区始终为 11 行；已放置快捷方式停留在原行 |
| 考试区随日程卡片、SPOC 段随待办卡片显示或隐藏，不单独设开关 | 无考试、SPOC 独立开关 |
| 子页面（`/schedule`、`/exams`、`/spoc`、`/bykc`）不受主页卡片开关影响，仍按各自流程取数 | 关闭卡片后子页面数据正常 |
| 五张卡片全部关闭时，功能区只显示快捷方式（仍为 11 行） | 页面正常，无报错 |
| 开关状态持久化 | 刷新浏览器后保持 |
| 时钟行提供“仅时钟与背景”切换按钮；进入后隐藏搜索框、时钟行按钮与整个功能区，只显示时钟与背景 | 页面上仅剩时钟与背景 |
| 该模式不显示切换按钮；点击视口任意位置回到完全功能模式，键盘可 Tab 聚焦后按 Enter 退出 | 可随时退出；恢复后各卡片按缓存优先加载 |
| 进入该模式时不发起功能区数据请求；退出后再刷新 | 无多余请求 |
| 模式选择持久化；只在 `/` 生效，子页面不受影响 | 刷新后仍在该模式；子页面显示正常 |
| 切换模式时背景黑色遮罩交叉淡入淡出（200ms，ease-out）；系统开启“减少动态效果”时不播放 | 遮罩不突变 |

### 3.13 缓存、刷新与错误

| 需求 | 验收 |
| --- | --- |
| 缓存优先：进入页面先展示上次缓存，再后台请求最新数据 | 有缓存时首屏直接有内容 |
| 请求成功：更新数据、更新缓存时间 | 状态显示“已同步”及时间 |
| 请求失败：保留缓存并标注缓存时间；认证失效时标题标签显示“已失效/未登录” | 断网/上游失败时缓存仍可读 |
| 提供手动刷新；不做定时轮询 | 点击刷新可重新请求；无自动数据轮询 |
| 无缓存且请求失败：显示错误与重试，不显示成空数据 | “取不到数据”与“没有数据”文案不同 |
| 首次使用未登录、无缓存：显示引导与空状态 | 页面能引导到设置页完成登录 |
| 课表、考试、SPOC、博雅已选课程、博雅广场、阳光各自独立状态，单个失败不阻塞其他模块 | 单源失败时其他模块仍可用 |
| 清除缓存与退出登录分开 | 清除缓存不影响登录状态；退出登录不清除本地待办与偏好 |
| localStorage 不可用或损坏：给出提示，降级为内存状态，不阻塞页面 | 页面仍可使用 |

## 4. 页面与路由

| 路由 | 页面 |
| --- | --- |
| `/` | 主页：时钟/日期、搜索、背景、快捷入口、日程（含考试区）、待办（含 SPOC）、博雅课程广场卡片、阳光打卡、专注；支持完全功能模式与仅时钟与背景模式 |

## 5. 通用规则

- 单用户；数据只存本机，不做云端同步。
- 桌面优先，最小支持宽度约 1024px；不做移动端布局。
- 时间按浏览器本地时区显示；教务时间按学校原始时间解释。
- 只读边界：教务数据仅做只读查询；仅保留登录、登出、验证码、派生重试与本地背景目录设置所必需的写请求，不提供任何教务业务写操作（提交、打卡、选退课、签到、附件下载）。
- 凭据只在设置页输入，由中继加密保存；前端仅在登录请求瞬间持有密码，不写入 localStorage。
- 技术约束：Vue 3 Composition API + `<script setup lang="ts">`、TypeScript strict、Vite、Tailwind CSS、Vue Router 4；状态用 reactive composable，不引入 Pinia；HTTP 统一封装在 `src/api/client.ts`。
- 本地中继是本项目唯一后端，仅本机访问；生产环境由本地 Express 服务同源提供构建产物与中继接口，不引入其他后端，不引入 SSR。

## 6. 边界与失败情况

- 首次使用：未登录、无缓存，各模块显示引导与空状态，不显示成“无数据”；本地待办、番茄钟、快捷入口仍可用。
- 登录账号或密码错误：提示错误，不清除缓存与已有设置。
- 验证码错误或过期：提示并刷新验证码，可直接重试。
- 密码过期或账号存在安全风险：提示用户先在浏览器处理，不自动跳过。
- 登录成功但单源派生失败：该源显示“派生失败”与重试，其余源正常。
- 会话过期且自动重登失败：对应数据源显示“已失效”，保留缓存并标注时间。
- 登录状态校验失败（中继不可达或上游超时）：卡片按自身请求结果显示缓存或加载失败与重试，不显示成“未登录”。
- 凭据文件损坏、密钥缺失或无法解密：视为未登录，提示重新登录，不白屏。
- 凭据目录不可写：提示无法保存登录状态，仍可在本次运行内使用会话。
- 网络失败/上游超时：保留缓存；无缓存时显示错误与重试。
- 空数据与失败分开：不能把“取不到数据”显示成“无课/无考试/无作业/无课程”。
- 周次边界：首周/末周禁用越界切换。
- 无未结束考试：主页考试区与 `/exams` 显示空状态。
- SPOC 无截止时间：列表显示并标注；已截止不显示。
- 重复待办：顺延到未来最近一次；历史完成项保留。
- 背景目录无权限、被删除或为空：回退内置背景并提示，保留路径。
- 背景图片全部不可用：回退内置背景，不出现破图。
- 五张卡片全部关闭：功能区只剩快捷方式，仍为 11 行，编辑与拖拽仍可用。
- 仅时钟与背景模式被持久化后刷新：保持该模式，点击视口任意位置仍可退出。
- 仅时钟与背景模式期间数据不刷新；退出后按缓存优先补齐。
- 番茄钟提示音被浏览器拦截：不阻塞计时，可再次尝试播放。
- 通知权限被拒绝或浏览器不支持：开关不可用或回到关闭，提示音与自动流转不受影响。
- 阶段时长不超过 1 分钟：不发送“结束前 1 分钟”通知，只在结束时通知。
- 页面后台导致计时延迟：按结束时间校正，跨过多个阶段时直接进入当前阶段，不补发历史通知。
- 中继未启动：设置页显示连接错误与启动提示，登录不可用；本地待办、番茄钟、快捷入口仍可用。
- localStorage 不可用或损坏：提示并降级为内存状态，不阻塞页面。

## 7. 假设与依赖

- byxt 接口支持当前用户、周次、周课表、考试查询；依据参考 A/B。
- SPOC 接口支持作业列表、详情、成绩字段；凭据由统一登录派生。
- 博雅接口支持已选课程、课程广场分页与详情；阳光接口支持学期/当周概览。
- 真实数据验收需要本地中继、有效学号与密码、校内网络或已连接的 VPN；未登录时只能验收界面、缓存与错误路径。
- 内置背景图需在仓库中提供；未提供时使用深色底或渐变兜底。
- 视觉布局以 `docs/ui-lowfi.md` 为准；接口细节以 `docs/api.md` 为准；技术设计以 `docs/trd.md` 为准。
