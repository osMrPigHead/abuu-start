# 航启主页 / BUAA-Start PRD

## 1. 目标与用户

- 面向**单用户**的桌面浏览器主页。
- 提供快捷入口、待办、番茄钟，以及北航教务信息的**只读**聚合。
- 前端为 Vue 3 SPA，无 SSR；通过**本地只读中继**访问教务系统。
- 不面向多用户，不做移动端适配。

## 2. 范围

### 2.1 本期必须

- 主页基础：时钟与日期、Bing 搜索、随机背景、快捷入口。
- 待办：本地待办 + SPOC 待办聚合。
- 番茄钟。
- 教务聚合：常态课表、考试、SPOC 作业。
- 认证、缓存、刷新与按数据源隔离的错误状态。

### 2.2 后续规划（本期不验收）

- 博雅课程：已选课程日程 + 课程广场只读浏览（筛选、分页、详情）；不做选课、退课、签到。
- 阳光打卡：学期累计次数/目标；不做打卡。
- 快捷入口：自定义图标、分组。
- 番茄钟：桌面通知。
- 认证：应用内统一学号/密码登录。
- 凭据：由本地中继加密存储与清除。

以上内容均不在本期验收；本期主页不出现博雅/阳光聚合卡片或详情页，仅保留其快捷入口。

### 2.3 非目标

- 多用户、账号体系、权限管理。
- 移动端适配；仅保证桌面端。
- SSR、Pinia、React。
- 任何写入操作：作业提交、阳光打卡、博雅选退课/签到、教务管理操作。
- 研究生 GSMIS 课表；本期仅支持本科 byxt。
- 教务系统管理后台、成绩管理、教室预约等未列出的功能。

### 3.8 认证与本地中继

| 需求 | 验收 |
| --- | --- |
| 设置页 `/settings` 提供“本研教育管理系统 Cookie”和“SPOC 凭据（Token + RoleCode）”两个凭据区 | 两个凭据区可保存、清除；SPOC 凭据含 Token 与 RoleCode 两个字段 |
| 每个数据源显示“未配置/已配置/已失效”；保存后触发一次校验 | 状态随保存与校验结果变化 |
| 支持清除单个凭据、清除全部凭据、清除缓存；凭据与缓存分开清除 | 清除后对应数据消失，未清除部分不受影响 |
| 凭据（Cookie、Token、RoleCode）存 localStorage；不写入 URL、不写入中继日志、不发往第三方；仅随本地请求发送给中继 | 地址栏、中继日志与第三方请求中无凭据明文（浏览器开发者工具中的本地请求除外） |
| 本地中继仅监听 `127.0.0.1`，按只读接口白名单转发 | 非本机不可访问；未列出的路径被拒绝 |
| 中继拒绝写方法与非白名单路径 | 构造写请求或未列路径时返回错误 |

| 课表、考试、SPOC 各自独立状态，单个失败不阻塞其他模块 | 单源失败时其他模块仍可用 |

### 3.9 缓存、刷新与错误

| 需求 | 验收 |
| --- | --- |
| 缓存优先：进入页面先展示上次缓存，再后台请求最新数据 | 有缓存时首屏直接有内容 |
| 请求成功：更新数据、更新缓存时间 | 状态显示“已同步”及时间 |
| 请求失败：保留缓存，显示“缓存于 YYYY-MM-DD HH:mm” | 断网/上游失败时缓存仍可读 |
| 提供手动刷新；不做定时轮询 | 点击刷新可重新请求；无自动轮询 |
| 无缓存且请求失败：显示错误与重试，不显示成空数据 | “取不到数据”与“没有数据”文案不同 |
| 首次使用无凭据、无缓存：显示引导与空状态 | 页面能引导到设置页配置凭据 |

| 路由                    | 页面                                   |
| --------------------- | ------------------------------------ |
| `/`                   | 主页：时钟/日期、搜索、背景、快捷入口、课表摘要、最近考试、待办、番茄钟 |

## 5. 通用规则

- 单用户；数据只存本机，不做云端同步。
- 桌面优先，最小支持宽度约 1024px；不做移动端布局。
- 时间按浏览器本地时区显示；教务时间按学校原始时间解释。
- 只读：不提供任何提交、打卡、选退课、签到、管理入口。
- 技术约束：Vue 3 Composition API + `<script setup lang="ts">`、TypeScript strict、Vite、Tailwind CSS、Vue Router 4；状态用 reactive composable，不引入 Pinia；HTTP 统一封装在 `src/api/client.ts`。
- 本地只读中继是本项目唯一后端；除它之外不引入其他后端，不引入 SSR。

## 6. 边界与失败情况

- 首次使用：无凭据、无缓存，各模块显示引导与空状态。
- 凭据失效：对应数据源显示“需重新认证”，保留缓存并标注时间。
- 网络失败/上游超时：保留缓存；无缓存时显示错误与重试。
- 空数据与失败分开：不能把“取不到数据”显示成“无课/无考试/无作业”。
- 周次边界：首周/末周禁用越界切换。
- 无未开始考试：主页卡片显示空状态。
- SPOC 无截止时间：列表显示并标注；已截止不显示。
- 重复待办：顺延到未来最近一次；历史完成项保留。
- localStorage 不可用或损坏：给出提示，降级为内存状态，不阻塞页面。
- favicon/背景图加载失败：使用占位或渐变，不出现破图。
- 番茄钟提示音被浏览器拦截：不阻塞计时，可再次尝试播放。
- 本地中继未启动：前端显示连接错误与启动提示，不白屏。

## 7. 假设与依赖

- byxt 接口支持当前用户、周次、周课表、考试查询；依据参考 A/B。
- SPOC 接口支持作业列表、详情、成绩字段；认证使用 Token + RoleCode，依据参考 B 与 HAR。
- 本地中继可由 Node 实现，按来源注入 Cookie 或 Token/RoleCode，仅本机访问；具体端口、启动脚本与错误结构留给 TRD。
- 真实数据验收需要本地中继 + 有效凭据；无凭据时只能验收界面、缓存与错误路径。
- 内置背景图需在实施阶段加入仓库；未加入前用渐变兜底。
- 视觉布局以 `docs/ui-lowfi.md` 为准；接口细节以 `docs/api.md` 为准；技术设计以 `docs/trd.md` 为准。本 PRD 只定义需求。
