## 关于本 UI 布局文档

- 本文档作为 UI 布局方式的唯一来源
- 当本文档与 PRD 冲突时，立即停止生成并要求用户确认需求
- 风格不包括颜色，仅指字重；日程高亮的“暖色/冷色”是功能状态语义，不定义具体色值

## 主页

显示为两行

1. 时钟与搜索
	- 左对齐显示时钟（分两行）
		1. 日期，显示为 YYYYMMDD DDD，如 20261026 Mon，较小字号
		2. 时间，显示为 HH:mm:ss，如 12:00:00，较大字号
	- 右对齐显示搜索框
		- 半透明虚化背景，半透明细边框
		- 中等字号
		- 左侧搜索框右侧搜索图标，搜索图标需要可点击，但不需要强调背景
	- 时钟行右侧提供设置、新建、编辑按钮，自右向左依次为设置、仅时钟与背景模式、编辑、新建
		- 设置：进入 `/settings`
		- 新建：打开新建快捷方式弹窗
		- 编辑：切换快捷方式编辑状态；编辑状态下可拖到任意一行并调整行内顺序，快捷方式右侧显示编辑按钮
		- 仅时钟与背景模式：眼睛图标；切换到仅时钟与背景模式
2. 功能区（左对齐行式瀑布流布局，固定 11 行）
	- 五张功能卡片可单独关闭，见「设置 / 主页卡片」
	- 关闭后卡片不显示，同列后续卡片上移，功能区仍保持 11 行，快捷方式可用行数不变
	- 左列自上而下为日程、待办；右列自上而下为博雅课程广场、专注、阳光打卡
	- 右列卡片紧贴起始行不晚于它的最后一张左列大卡的右缘，间距 0.75rem；左列为空时从最左侧开始
	- 下列行数与位置为五张卡片全部开启时的布局
	1. 日程卡片（占 5 行，位于左上角）
	2. 博雅课程广场卡片（占 5 行，位于日程右侧，宽度与专注卡片一致）
	3. 待办卡片（占 6 行，位于左下角，从第 6 行开始）
	4. 专注卡片（占 4 行，位于待办右侧，从第 6 行开始）
	5. 阳光打卡卡片（占 2 行，位于专注卡片下方，与专注卡片同列同宽）
	6. 其他每个快捷方式显示为一个卡片（每个卡片只能占一行，可放在 11 行中的任意一行）

## 全局入口

- 点击日程卡片进入 `/schedule`
- 点击考试区进入 `/exams`
- 点击 SPOC 区进入 `/spoc`
- 点击博雅课程广场卡片中的课程卡片打开课程详情 modal
- 点击博雅课程广场卡片中的「查看全部」进入 `/bykc`
- 点击时钟行设置按钮进入 `/settings`
- 所有子页面（`/schedule`、`/exams`、`/spoc`、`/bykc`、`/settings`）标题行右侧提供「返回主页」入口，样式以 SPOC 作业、博雅课程广场的返回按钮为准；点击回到 `/`

## 状态行

- 日程、考试、SPOC、博雅课程广场的卡片或页面，以及待办卡片中的 SPOC 段，在内容下方显示状态行：已同步（含时间）、缓存于 `YYYY-MM-DD HH:mm`、失败与重试
- 无数据与取数失败使用不同文案
- 无凭据时显示引导，点击进入 `/settings`

## 日程卡片

分两行

1. 课表信息（仅常规课表）
	- 分两行显示今日和明日课表，风格参照参考 A
	- 行首左对齐分三行显示：第一行大字显示日（DD）；第二行小字显示周内日与今天 / 明天；第三行显示日期所属周序号，不显示“缓存”字样
	- 行中显示课程卡片（分 3 行）
		1. 节次和时间，如“第 1-2 节 08:00-09:35”，其中节次用弱强调风格，时间用次要风格，字号略小于节次
		2. 课程名，用强调风格，字号大于节次
		3. 地点；教师有则附后，显示为“地点 · 教师/周次描述”，风格和字号与常规课程时间相同
	- 课程卡片高度适应内容，不随日程卡片剩余空间纵向拉伸；卡片内容纵向居中
	- 课程高亮：提前边界内即将开始的课程用暖色并以 1.1s 周期闪烁，进行中的课程用冷色且不闪烁，其他情况不高亮
	- 内容首行（标题下方）显示下节课信息，字号 11px；提前边界内用暖色，进行中用冷色，二者同时成立时仍显示“正在上课”但用暖色，其他情况不高亮
2. 考试信息
	- 本期不接入考试数据：三张等宽占位卡，文案“最近考试 / 待接入”，不显示真实字段；以下为后续接入口径
	- 在一行内均匀布局显示最近三场未开始考试，若少于三场，保持均匀布局，填满一行
	- 考试显示为卡片
		1. 考试课程名，风格和字号与课程名相同
		2. 时间，用正文风格，字号与节次相同，显示为“MM 月 DD 日 HH:mm – HH:mm”，连接符使用 `en dash`，左右需要空格
		3. 地点，用正文风格，字号与节次相同，显示为“X 校区 / 具体地点”，分隔符使用 ASCII 斜杠，左右需要空格
		4. 剩余天数，用强调字重，字号与节次相同；当天显示“今天 HH:mm”

## 待办卡片

左右两栏，各占一半宽度，中间以细分割线分隔；左栏为自定义待办，右栏为 SPOC 作业。两栏标题行顶部对齐，列表超出时各自在栏内纵向滚动

1. 自定义待办（本地）
	- 段首提供“新增”入口；每条右侧提供“编辑”“删除”图标按钮
	- 一行显示一个待办，左侧显示完成勾选框；完成勾选框、优先级标签、编辑与删除按钮在整条待办内纵向居中
	- 标题用正文风格，字号大于截止日期
	- 标题右侧用标签显示优先级（高/中/低），标签字号与标题相近
	- 第二行显示截止日期；无截止时间时不显示该行
	- 完成后置后显示，并保留完成勾选
	- 新增/编辑弹窗字段：标题、截止时间、备注、优先级、重复
2. SPOC 作业
	- 一行显示一个作业，只读，无完成勾选框；点击打开详情 modal
	- 待办标题行右侧显示提交状态标签（未提交/未知）
	- 作业卡片排版分三行，风格与待办一致
		1. 课程和教师名，显示为“课程·教师”，用次要风格
		2. 待办标题，用正文风格，字号大于课程和教师名
		3. 截止日期，用强调字重，字号与课程和教师名相同；无截止时间显示“无截止时间”

## 专注卡片

### 设置状态

- 四个配置项按 2×2 排列：专注时长、短休时长、长休时长、每几轮进入长休
- 每个配置项标签在上，输入框与单位在同一行；输入框宽度一致、内容右对齐
- 输入栏与开始按钮风格与搜索框一致

### 专注状态

最多五行；预计完成行在暂停或未开始时隐藏。

- 第一行：当前阶段，显示“专注”/“短休”/“长休”，居中对齐，用次要风格
- 第二行：剩余时间，居中对齐；显示风格与时钟类似，但字号适配卡片
- 第三行：预计完成时间，显示为“HH:mm”，用次要风格，字号小于时间，居中对齐；仅运行中且未暂停时显示
- 第四行：已完成轮次，显示为“已完成 X 轮”，用次要风格，字号小于时间，居中对齐
- 第五行：开始/暂停/继续、重置按钮，风格与搜索框一致

## 阳光打卡卡片

- 固定占 2 行，位于专注卡片正下方，与专注卡片同列同宽
- 标题右侧显示状态标签：已同步 / 缓存于 `YYYY-MM-DD HH:mm` / 已失效 / 待接入；同步中显示“同步中”，无缓存且失败显示“加载失败”
- 标题右侧状态标签旁提供操作：可重试时显示“重试”，无凭据或已失效时显示“设置”；标签与文字过长时截断
- 标题下为上下两条进度：
	1. 学期：右侧显示“次数 / 目标”，下方为细进度条
	2. 本周：右侧显示“次数 / 周限制”，下方为细进度条
- 进度按次数除以目标计算；超过目标或限制时进度条封顶，文字保留实际次数
- 无详情入口，不提供打卡、补卡、上传或任何写操作
- 无凭据且无缓存时显示引导；加载失败保留缓存并标注时间，不显示成“0 次”

## 博雅课程广场卡片

- 固定占 5 行，位于日程卡片右侧，宽度与专注卡片一致
- 标题右侧显示状态标签；标签旁在可重试时显示「重试」，未配置或已失效时显示「设置」；标签与文字过长时截断
- 内容纵向排列 3 门课程，每门课程显示为卡片（样式与考试、SPOC 作业卡片一致，可点击）
	1. 课程名，单行截断，用强调字重
	2. 时间，显示为 `MM-DD HH:mm`；开始时间缺失时显示「时间待定」
	3. 地点，单行截断；地点为空时不显示该行
	- 点击课程卡片打开课程详情 modal
- 课程来自课程广场第 1 页，随机取 3 门；不足 3 门显示实际数量
- 底部操作行：左侧「查看全部」进入 `/bykc`；右侧「换一批」
- 「换一批」重新随机，尽量不与当前 3 门重复；无法避免时允许重复
- 无凭据且无缓存时内容区显示引导，「换一批」禁用；加载失败保留缓存并标注时间，无缓存且失败显示错误与重试，不显示成「暂无课程」
- 课程广场分页列表与课程详情 modal 属于 `/bykc` 页面，不在卡片内展开

## 博雅课程广场

- 路由 `/bykc`；页码由查询参数 `?page=n` 决定，非法或越界时回退到有效页
- 页首左侧显示标题「博雅课程广场」与一行说明（有数据时显示总门数与本页 / 总页数），右侧提供返回主页入口
- 标题下方状态行：已同步、缓存于 `YYYY-MM-DD HH:mm`、失败与重试、无凭据引导
- 分页列表，每页 12 条，一行一门课程，显示为卡片；整条卡片可点击打开课程详情 modal
	1. 第一行：课程名，右侧显示状态标签（已选 / 可选 / 已过期 / 人数已满 / 预告 / 选课结束）
	2. 时间，显示为 `MM-DD HH:mm – HH:mm`，连接符使用 `en dash`，左右需要空格；结束时间缺失时只显示开始时间
	3. 地点 · 教师；地点为空显示「地点待定」，教师为空不显示占位
- 列表按上游返回顺序展示，不额外排序；不做筛选与搜索
- 底部居中显示分页：上一页、当前页 / 总页数、下一页；首页禁用上一页，末页禁用下一页；无数据时不显示分页
- 无数据时显示空状态；加载、失败与缓存状态在状态行显示

## 博雅课程详情 modal

- 遮罩覆盖整页，点击遮罩、按 Esc 或点击右上关闭按钮关闭；打开时锁定页面滚动，关闭后焦点回到触发卡片
- 打开/关闭时遮罩与面板整体渐入渐出，与 SPOC 详情 modal 一致：进入 150ms ease-out，退出 100ms ease-in
- 面板居中，最大宽度为 2xl，最大高度为视口的 80%；内容超出时面板内部滚动
- 头部：课程名，右侧显示状态标签与关闭按钮
- 信息区：时间、地点、教师（有则显示），标签与内容成对排列
- 课程简介：纯文本展示，保留换行；内容过长时在区域内滚动
- 底部右侧提供「关闭」，不提供选课、退课、签到、下载或任何写操作
- 打开时先显示列表已有的课程名、时间、地点、教师与状态，简介区域显示加载状态；详情失败时保留已有字段并显示错误与重试

## 快捷方式卡片

- 一行内显示，显示图标（如有）和设置的标题，限制最大宽度和最小宽度
- 快捷方式可放在 11 行中的任意一行，包括空行；每行数量不限，超出视口后横向滚动，不自动换行
- 功能区固定 11 行；关闭功能卡片不改变行数与可用放置区
- 每行从该行大卡右侧开始顺序排列；大卡之间的 0.75rem 窄缝不作为放置区
- 顶部时钟行提供新建、编辑按钮；新建使用弹窗，字段为标题 + URL
- 新建的快捷方式默认追加到第 1 行末尾，并横向滚动到新卡片
- 编辑按钮为开关：开启后快捷方式不再跳转，进入拖拽排序状态，可拖到任意一行，也可调整行内顺序
- 编辑状态下显示 11 行放置区，拖拽时高亮目标行并显示插入位置；每个快捷方式右侧显示无边框、无背景的编辑按钮，点击打开编辑弹窗；弹窗内提供删除
- 弹窗的具体布局由助手决定

## 日程详情

- 顶部显示当前“第 N 周”和日期范围
- 整页页首与页尾各提供一组周次切换（上一周 / 跳转周 / 下一周）；首周/末周禁用越界按钮
- 一行一天，周一至周日共 7 行，每行显示为与日程卡片课表信息相同的样式
- 每行行首分三行显示：第一行大字显示日（DD），第二行显示周内日，第三行显示周序号；本期不接入考试数据，不显示考试标记
- 课程卡片：节次/时间、课程名、地点 · 教师/周次描述；卡片拉伸填充行高，卡片内容纵向居中
- 课程高亮：提前边界内即将开始的课程用暖色并以 1.1s 周期闪烁，进行中的课程用冷色且不闪烁，其他情况不高亮
- 空周显示“无课”；加载、失败与缓存状态在上方状态行显示

## 考试详情

- 本期为占位页，不展示真实考试数据；以下保留后续接入口径
- 未开始考试按月分组，组内按考试时间升序；已结束考试统一置底，组内按时间倒序并标注“已结束”
- 一行一场考试，显示为卡片，填充整行；详情页卡片背景与其他卡片一致（主页考试卡片背景保持不变）
- 卡片字段：课程名、时间（“MM 月 DD 日 HH:mm – HH:mm”）、地点（“X 校区 / 具体地点”）、座位号、周次、剩余天数；当天显示“今天 HH:mm”
- 无未开始考试时显示空状态；加载、失败与缓存状态在上方状态行显示

## SPOC 列表

- 仅显示未提交且未截止的作业；已提交、已截止不显示
- 按截止时间升序，无截止时间置后
- 一行一项作业，显示为卡片（卡片分四行）；点击卡片打开详情 modal
- 无作业时显示空状态；加载、失败与缓存状态在上方状态行显示

1. 第一行：作业标题，右侧显示提交状态标签（未提交 / 未知）
2. 课程和教师名，显示为“课程·教师”，用次要风格，字号小于待办标题
3. 开始时间，用次要风格，字号与课程和教师名相同
4. 截止日期，用强调字重，字号与课程和教师名相同；无截止时间显示“无截止时间”

## SPOC 详情 modal

- 从 SPOC 列表卡片或待办卡片 SPOC 段打开；遮罩覆盖整页，点击遮罩、按 Esc 或点击右上关闭按钮关闭
- 打开时锁定页面滚动，关闭后焦点回到触发卡片
- 打开/关闭时遮罩与面板整体渐入渐出：进入 150ms ease-out，退出 100ms ease-in
- 面板居中，最大宽度为 2xl，最大高度为视口的 80%；内容超出时面板内部滚动
- 头部：作业标题、课程、教师（有则显示）；右侧显示提交状态标签（已提交 / 未提交 / 未知）与关闭按钮
- 信息区：开始时间、截止时间、提交状态、成绩（无成绩显示“暂无成绩”）
- 作业说明：纯文本展示，保留换行；内容过长时在区域内滚动
- 附件区：有附件时显示附件名称，不提供下载
- 无效 id：显示“未找到”并保留关闭入口
- 加载、失败与缓存状态在顶部状态行显示；状态行提供重试与前往设置
- 底部右侧提供「关闭」，不提供提交、附件下载或任何写操作

## 设置

- 凭据区，上下排列
	1. 本研教育管理系统 Cookie：文本输入区、保存、清除、状态标签（未配置/已配置/已失效）、校验按钮
	2. SPOC 凭据：Token、RoleCode 两个输入框、保存、清除、状态标签（未配置/已配置/已失效）、校验按钮；本期保留但禁用，标注“待接入”
	3. 博雅课程 auth_token：输入框、保存、清除、状态标签（未配置/已配置/已失效）、校验按钮；保存后调用一次博雅资料接口校验
	4. 阳光打卡：UID、token 两个输入框、保存、清除、状态标签（未配置/已配置/已失效）、校验按钮；保存后调用一次阳光概览接口校验
- 保存后自动校验一次；已保存的凭据只显示掩码（UID 不是密钥，按原值显示）
- 每个凭据区附简短获取说明：byxt 填浏览器 Cookie；SPOC 填开发者工具 Network 中任一 SPOC 请求的 Token 与 RoleCode；博雅填开发者工具 Network 中任一 sscv 请求的 auth_token；阳光填开发者工具 Network 中任一 ygdk 请求 Form Data 中的 UID 与 token

- 日程高亮区：提前高亮分钟数输入框（默认 30，范围 0–180，0 表示不提前高亮）、保存按钮、当前生效值；下方显示暖色“即将开始”与冷色“进行中”图例
- 主页卡片区：五个开关（日程、博雅课程广场、待办、专注、阳光打卡），默认全部开启；切换后立即生效并持久化
	- 每个开关一行：左侧为标题与简短说明，右侧为开关，样式与番茄钟桌面通知开关一致
	- 关闭后主页不显示该卡片，并停止请求对应数据源；重新开启后按缓存优先刷新
	- 考试区随日程卡片、SPOC 段随待办卡片显示或隐藏，不单独设开关
- 背景区：位于「主页卡片」之后
	- 区块标题「背景」，右侧显示状态标签：未配置时显示「内置背景」；已配置且有可用图片时显示「已配置 · N 张」；已配置但目录异常时显示「目录异常」，目录可用但没有图片时显示「无可用图片」，后两者用琥珀色

		- 保存：输入框非空时可用
		- 重新扫描、清除：已配置目录时可用
		- 请求进行中禁用按钮，按钮文字分别显示「保存中」「扫描中」「清除中」
	- 操作行下方显示两行状态，均单行截断

	- 主页不新增背景状态提示；异常时静默回退内置背景，异常说明仅在设置页背景区显示

## 仅时钟与背景模式

以参考 A，body 去除 focusing class 的效果为基准，但减小背景的黑色渐变遮罩；具体而言，相对于本项目的完全功能模式：

- 背景的黑色渐变遮罩透明度更低、范围更小
- 不显示功能区、时钟右侧的功能按钮和原有的时钟
- 时钟显示在左下角，首行为时间、次行为日期，字号与参考 A保持一致，但采用 rem 或 px 为单位
- 不显示切换按钮；点击视口任意位置回到完全功能模式（键盘可 Tab 聚焦后按 Enter）

对于切换动画：

- 背景的黑色渐变遮罩在两种模式间交叉淡入淡出（200ms，ease-out）
- 完全功能模式下时钟与搜索行向上渐隐或向下渐入
- 完全功能模式下功能区整体向下渐隐或向上渐入
- 仅时钟与背景模式下时钟向左渐隐或向右渐入
